## 它会怎样
| 状态 | 什么时候 | 团子的样子 |
|---|---|---|
| 悠闲 | 慢慢打字或没在打 | 眯眼微笑，小芽挺立 |
| 警觉 | 开始敲快了 | 盯着你，头顶感叹号 |
| 紧张 | 持续快速打字 | 眼神乱瞟、皱眉、冒汗 |
| 慌张 | 压力过 65 | 泪眼尖叫，满窗口乱跑 |
| 崩溃 | 压力爆表 | 摊成一滩，飘出麻糬灵魂；约 14 秒后自己爬起来 |
| 睡觉 | 5 分钟没动静 | 打瞌睡 |

**头顶小芽就是压力计**：挺立 → 下垂 → 发黄 → 枯掉。摸摸它、喂块饼干，小芽会重新挺起来。

## 和团子互动
| 怎么做 | 团子的反应 |
|---|---|
| **单击**戳它 | 被戳扁一下，“干嘛戳我” |
| 2.5 秒内连戳 **5 下** | 转圈眼加星星，晕了 |
| 鼠标在它身上**来回蹭** | 被摸摸，冒爱心，压力 -15 |
| **双击** / 托盘「投喂小饼干」 | 抱着饼干嚼嚼嚼，压力 -25（每天最多 3 块） |
| **拖着走** | 被拎起来晃来晃去，松手落地 |
| 鼠标**停在它身上** 1.5 秒 / 托盘「今日战绩」 | 今天敲了多少下、崩溃几次、亲密度 ♥ |
| 今天第 500 / 1000 / 3000 / 5000 / 10000 / 20000 下 | 撒彩带庆祝 |
| 连续打字 50 分钟没歇 | 伸懒腰，提醒你起来动动 |
| 连按 3 次退格 / 回车 / Ctrl(Cmd)+S | 捂脸 / 跳一下 / 点赞 |
| 工作日 17:30 | 背上小书包下班，报一下今天的总按键数；之后还在打字，它会探头问「你怎么还在加班…」，第二天 09:00 回来 |

## 托盘菜单
暂停感知键盘 · 完全穿透（彻底不挡鼠标，这时也摸不到它）· 灵敏度 低/中/高 · 投喂小饼干 · 今日战绩 · 下班 / 回来上班 · 回到右下角 · 开机自启 · 退出

只有团子身上能点，透明的地方会自动穿透，不挡桌面。重复启动不会冒出第二只，只会把现有的召回右下角。

## 隐私
团子只数你按了几下键，**从不记录按了哪个键、打了什么内容**。统计只存在本机，每天零点重置；亲密度永久累积。

## 安装
到 [Releases](https://github.com/supersuperKK/typing-panic-pet/releases/latest) 下载：
- **Windows**：`-setup.exe` 或 `.msi`
- **Mac**：Apple 芯片选 `aarch64.dmg`，Intel 选 `x64.dmg`

安装包没有签名，第一次打开会被拦：
- **Windows**：点「更多信息」→「仍要运行」
- **Mac**：右键 →「打开」，或到「系统设置 → 隐私与安全性」点「仍要打开」。然后在「辅助功能」（部分系统还要「输入监控」）里勾选 TypingPanicPet 并重启程序。没给权限时团子会捂着耳朵说听不到键盘，点它一下直接打开设置。

## 从源码运行
1. 装好 Rust（https://rustup.rs）和 Node 18+
   - Windows：还需要 Visual Studio 的「C++ 生成工具」
   - Mac：`xcode-select --install`
2. 在项目根目录：
   ```bash
   npm install
   npm run dev     # 开发模式，第一次编译要几分钟
   npm run build   # 打包，产物在 src-tauri/target/release/bundle/
   npm test        # 跑状态机和下班时间测试
   ```
3. 只想看界面：用浏览器打开 `src/index.html`，在页面里打字即可。F2 预览下班，F3 投喂，F4 看战绩。

推一个 `v*` 标签会触发 GitHub Actions（`.github/workflows/release.yml`），自动打出 Windows 和两种 Mac 的安装包，放进草稿 Release。

## 调手感
参数在 `src/pet.js` 顶部的 `DEFAULTS`：
| 参数 | 默认 | 作用 |
|---|---|---|
| calmKps | 1.5 | 每秒低于这么多键，压力回落 |
| alertKps | 1.5 | 平滑后超过就警觉 |
| nervousKps | 3.5 | 平滑后超过就紧张 |
| panicStress | 65 | 压力超过就慌张乱跑 |
| gain | 0.6 | 压力上涨速度 |
| decay | 1.2 | 压力回落速度（每秒） |
| recoverBelow / collapseDecay | 30 / 5 | 崩溃后每秒掉 5，低于 30 爬起来 |

按默认值，每秒 4 键约 67 秒崩溃，每秒 6 键约 39 秒，每秒 8 键约 27 秒。下班时间和工作日在 `src/offwork.js` 的 `DEFAULTS` 里改。

## 目录
```
src/            前端（纯 HTML/CSS/JS，无需打包工具）
  pet.js        宠物「大脑」：按键速度、压力、状态机（纯函数，可单测）
  main.js       渲染与事件
  interact.js   戳、摸、投喂、拖动等互动
  offwork.js    下班逻辑
  sprites/      精灵条（48×48 一帧，带四阶段小芽）
src-tauri/      Rust 外壳：透明置顶窗口、全局键盘监听、托盘、命中区穿透
test/           单元测试
tools/
  make_sprites.py  用代码画出全部精灵图，改表情、颜色后重跑即可
  make_icon.py     从团子精灵生成程序图标（16/24/32 像素手调）
docs/           README 用图
```
